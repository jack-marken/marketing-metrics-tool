

# Installation

Install Node v24.19.0 (references .nvmrc):

```bash
$ nvm i
```

Install NPM packages:

```bash
$ npm i
```

Create a `.env` file at the root path and add the Google Cloud Developer API key:

```text
GOOGLE_CLOUD_API_KEY=[add key here]
```

# Usage instructions

Start the server:

```bash
$ npm run server
```

In a new terminal, run the demo code:

```bash
$ node api_demo.js
```
